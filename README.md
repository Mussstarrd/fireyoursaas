# fireyoursaas.us

Static landing page for Fire Your SaaS — trade pricing & job-costing systems.

- `index.html` — the page (single file, no build step, no dependencies)
- `CNAME` — custom domain for GitHub Pages

## Publishing
GitHub Pages serves `index.html` from the default branch root.
To update: replace `index.html`, commit, push. Live in ~1 minute.

## Important
This repo is PUBLIC and contains the marketing page only.
Product workbooks (.xlsx) must never be committed here — a public repo
means free downloads. Products live in the private workshop repo and are
delivered only after payment.
